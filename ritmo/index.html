Referências iniciais: 140 g de proteína, 3.000 mL de água, 8 horas de sono. Ajusta com o profissional de saúde e de acordo com tua rotina.

Teus dados e backups

O app guarda os registros no armazenamento local deste navegador. Não possui conta, banco de dados online nem sincronização entre aparelhos. Limpar os dados do Safari, usar navegação privada ou trocar de dispositivo pode apagar o histórico. Exporta uma cópia regularmente.

Importar substitui os registros locais pelo conteúdo do backup, depois de confirmação.

Privacidade: o conteúdo que registras fica no navegador. O endereço do site, caso seja publicado, pode ser público, mas os registros não são enviados automaticamente ao servidor de hospedagem. Evita usar dispositivos compartilhados.

Recomeçar do zero

Esta opção apaga todos os registros deste dispositivo. Recomendamos exportar um backup antes.
